    Instalação

    Como instalar

    Leva menos de um minuto.

    Windows

    1. Baixe o instalador. Clique em Baixar para Windows. Se o navegador avisar que o arquivo não é baixado com frequência, escolha Manter.
    2. Abra o instalador. Se aparecer “O Windows protegeu seu computador” (SmartScreen), clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o instalador não tem assinatura digital paga; o código é aberto e pode ser auditado.
    3. Escolha a pasta e conclua. O assistente deixa você mudar o local de instalação e cria atalhos na Área de Trabalho e no Menu Iniciar.
    4. Pronto. Abra o ZReader. Para atualizar, instale a versão nova por cima: seus dados são preservados.

    Android

    1. Baixe o APK. Toque em Baixar para Android no navegador do celular.
    2. Abra o arquivo. Toque na notificação de download ou abra o arquivo no app Arquivos.
    3. Permita a instalação. Se o Android pedir, toque em Configurações e ative Permitir desta fonte para o navegador ou gerenciador de arquivos que você usou. Volte e toque em Instalar.
    4. Confirme no Play Protect, se pedir. Se aparecer um aviso, toque em Mais detalhes e depois em Instalar mesmo assim. Depois, você pode desativar a permissão de fontes desconhecidas.

    FAQ

    Perguntas frequentes

    O ZReader é seguro? O Windows/Android mostrou um aviso.

    Os avisos aparecem porque o app é independente, não tem assinatura digital paga e não está em lojas oficiais. O código é aberto (MIT) e você pode conferir o SHA-256 dos arquivos na seção Downloads. Baixe sempre por esta página ou direto do GitHub Releases.

    Funciona no iPhone, no Mac ou no Linux?

    Ainda não. Hoje existem versões para Windows (64 bits) e Android. Acompanhe o repositório no GitHub para novidades.

    Como funciona a conexão com o MangaDex?

    O ZReader usa a API oficial do MangaDex. Para sincronizar biblioteca e progresso, você conecta sua conta com um Personal Client criado por você no MangaDex; as credenciais ficam criptografadas no seu dispositivo.

    Como atualizo para uma versão nova?

    Baixe a versão mais recente nesta página e instale por cima. No Windows, seus dados são preservados.

    O ZReader é afiliado ao MangaDex? De onde vêm os mangás?

    Não há afiliação oficial. Todo o conteúdo exibido no app é hospedado pelo MangaDex e seus grupos; o ZReader não hospeda nem altera conteúdo protegido por direitos autorais. Sempre que possível, apoie os autores e as editoras oficiais.
